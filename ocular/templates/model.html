Loading the trained weights {{ 'Model loaded' if predictor_status.mode == 'model' else 'Demo mode' }}

The weights file is about 160 MB, so it is tracked with Git LFS rather than as a regular file. Running the notebook (or training/train.py) produces ocular_disease_model.h5.

Placing it at models/ocular_disease_model.h5, or pointing ODR_MODEL_PATH at it, switches the app from demo mode to real predictions on the next start.

REST API
GET/api/v1/health

Reports whether the model or the demo predictor is active, and lists the classes in output order.

POST/api/v1/predict?heatmap=1

Multipart upload under the field file. Returns the top class, all eight probabilities, input warnings and timing; with heatmap=1 it also returns the Grad-CAM overlay as base64 JPEG.
